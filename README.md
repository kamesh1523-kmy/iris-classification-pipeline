# Iris Classification Pipeline

## Overview
A supervised machine learning project that classifies Iris flowers into three species using Logistic Regression and Decision Tree classifiers.

## Dataset
- Source: [Seaborn Iris Dataset](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv)
- Samples: 150
- Features: Sepal length, sepal width, petal length, petal width
- Target: Species

## Technologies
- Python
- Pandas and NumPy
- Scikit-Learn
- Matplotlib and Seaborn
- Jupyter Notebook / Google Colab

## Workflow
1. Load and explore the dataset.
2. Visualize feature relationships with a pairplot.
3. Split the data into training and testing sets (80:20).
4. Standardize features using StandardScaler.
5. Train Logistic Regression and Decision Tree models.
6. Evaluate accuracy, precision, recall, and F1-score.
7. Plot confusion matrices and decision boundaries.
8. Compare model performance.

## How to Run
Open `Multi_Class_Classification_Pipeline.ipynb` in Google Colab or Jupyter Notebook and execute the cells from top to bottom.

## Results
Model evaluation metrics and visualizations are included in the notebook.
